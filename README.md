# Kanban React

Aplicação de controle de tarefas no formato Kanban, com colunas para organizar o fluxo de atividades.

## Stack
- React
- JavaScript
- CSS

## Demo
https://qqi5wu-3000.csb.app/

## Como executar
O projeto pode ser aberto pela demo do CodeSandbox. Para execução local, instale as dependências declaradas em `package.json` e use o script de desenvolvimento configurado no projeto.
