# React Kanban

A task management application using a Kanban board, with columns to organize the flow of activities.

## Stack
- React
- JavaScript
- CSS

## Demo
https://qqi5wu-3000.csb.app/

## Run
The project can be opened through its CodeSandbox demo. For local execution, install the dependencies declared in `package.json` and use the development script configured by the project.
